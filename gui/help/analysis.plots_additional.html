analysis.plots_additional module

Дополнительные графики: облака точек MC, диаграмма T90–EH.

class analysis.plots_additional.AdditionalPlotter[source]

Bases: object

Построение дополнительных графиков, не связанных напрямую с результатами MCMC.

Позволяет визуализировать облака точек, сгенерированные для GRB, а также строить диаграмму T90–EH.

output_dir

Папка для сохранения графиков (по умолчанию ‘additional_plots’).

Type:

pathlib.Path

plot_clouds(clouds, grb_names=None, log_scale=True, save=False, save_path=None, ax=None, axes_dict=None)[source]

Универсальная отрисовка облаков точек.

Parameters:

  • clouds (list of dict) – Список словарей с полями ‘GRBname’, ‘sbolo_mc’, ‘e_pi_mc’, а также исходными ‘sbolo’, ‘sbolo_err’, ‘e_pi’, ‘e_pi_err_l’, ‘e_pi_err_u’.

  • grb_names (str, list of str or None, optional) – Имена GRB для отображения. Если None – все GRB серыми облаками. Если одно имя – детальный график с гистограммами. Если несколько – выбранные GRB цветными облаками на фоне всех.

  • log_scale (bool, optional) – Использовать логарифмический масштаб осей.

  • save (bool, optional) – Сохранить ли график в файл.

  • save_path (str or Path, optional) – Путь для сохранения (по умолчанию в self.output_dir).

  • ax (matplotlib.axes.Axes, optional) – Ось для рисования (только для режимов ‘all’ и ‘selected’).

  • axes_dict (dict, optional) – Словарь с ключами ‘main’, ‘top’, ‘right’ для режима одного GRB.

Returns:

fig

Return type:

matplotlib.figure.Figure or None
