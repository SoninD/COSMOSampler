class core.spectral_model.CPLModel(catalogue: pandas.DataFrame)[source]

Bases: BaseSpectralModel

Модель Cutoff Power Law (CPL) для спектра гамма-всплеска.

N(E) = A_norm * (E / E_norm)^alpha * exp(-E * (2 + alpha) / E_peak).

Parameters:

catalogue (pandas.DataFrame) – Каталог GRB, содержащий колонки: alpha, Epeak, enorm, norm, S_obs, S_obs_err, redshift, DEpeak_hi, DEpeak_low.
