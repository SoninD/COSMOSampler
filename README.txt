### COSMOSampler ###

Байесовский анализ космологических параметров и корреляции Амати по данным сверхновых (Pantheon) и гамма-всплесков (SWIFT).

1) Установка
Клонируйте репозиторий:
git clone https://github.com/SoninD/COSMOSampler.git
cd COSMOSampler

Установите необходимые библиотеки:
pip install -r requirements.txt


2) Запуск графического интерфейса
python gui/app.py

-Откроется стартовое меню, затем основное окно с левой панелью настроек и правой панелью для логов и графиков.

3) Как работать с GUI
-- Данные: выберите «Каталоги SWIFT/Pantheon» (по умолчанию) или загрузите свои CSV-файлы.

-- Фильтры каталогов: настройте диапазоны T90, красного смещения z, Epeak с помощью ползунков. Кнопка ↺ сбрасывает значения к исходным.

-- MCMC: задайте количество walkers, шагов, burn‑in и выберите режим для GRB (sigma_int или clouds). В режиме clouds параметр σ_int автоматически фиксируется.

-- Фиксировать параметры: отметьте, какие параметры зафиксировать, и введите значения.
   ⚠️ Важно: параметр кривизны Ω_k пока не поддерживается — не изменяйте его и не пытайтесь делать свободным. Оставьте его равным 0.
   Опции «Без сверхновых» / «Без гамма-всплесков» управляют доступностью полей.

--Папки: укажите, куда сохранять результаты, или загрузите предыдущую цепочку для продолжения.

-- Кнопки управления: «Запустить MCMC», «Продолжить MCMC», «Прервать MCMC», «Сохранить анализ».

-- Графики: после завершения MCMC доступны диаграмма Хаббла, trace plot, corner plot, posterior distributions. Сохранение графиков — через кнопки «Сохранить текущий» и «Сохранить все графики» (по умолчанию PDF).

-- Дополнительные графики: облака MC, диаграмма T90‑EH, спектры (CPL). Можно указать имена GRB через запятую.

-- Справка: встроенная HTML-документация открывается кнопкой «Справка» (в главном окне или в стартовом меню).

4) Консольный запуск
Для пакетной обработки используйте файл конфигурации configs/config.json. Пример лежит в configs/config.json

python .run_config.py configs/config.json

Поддерживаются команды run, resume, analyze. Пути в конфиге должны быть относительными или абсолютными.

5) Ручной запуск
Для быстрого тестирования выполните python .run_manual.py — скрипт проведёт полный цикл с параметрами, заданными в коде.
